### Spec Compliance Verification

**useUsers hook:**
- Uses `useQuery` with queryKey `['users']` ✓
- Calls `/api/users` endpoint ✓

**useTasks hook:**
- Accepts optional `TaskFilter` parameter ✓
- Uses queryKey: `['tasks', filter ?? null]` ✓
- Builds query string from `assignedToUserId`, `status`, `taskType` ✓
- Handles edge case: status/taskType can be 0 (falsy but valid) using `!== undefined` ✓

**useCompleteTask mutation (optimistic update):**
- Endpoint: PATCH `/api/tasks/{id}/complete` ✓
- onMutate: cancels ['tasks'] queries ✓
- onMutate: snapshots all ['tasks'] caches before update ✓
- onMutate: sets task status to TaskStatus.Completed in all snapshots ✓
- onError: rolls back all ['tasks'] caches to snapshots ✓
- onSettled: invalidates ['tasks'] and ['dashboard'] ✓

**useCreateTask mutation:**
- Endpoint: POST `/api/tasks` ✓
- Invalidates ['tasks'] and ['dashboard'] on success ✓

**useUpdateTask mutation:**
- Endpoint: PUT `/api/tasks/{id}` ✓
- Invalidates ['tasks'] and ['dashboard'] on success ✓

**useDeleteTask mutation:**
- Endpoint: DELETE `/api/tasks/{id}` ✓
- Invalidates ['tasks'] and ['dashboard'] on success ✓
